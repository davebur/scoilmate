# ScoilMate draft-content contract

Nine original single-answer MCQs, nine help lessons; all draft/unreviewed. Not a published seed bank. Each question has stable id plus revision, subject/track/levels, editorial year guidance (not official mandated sequence), candidate mapping, four keyed choices, one correct key, explanation, two ordered hints and a same-subject/track lesson reference. Versions are positive integers. Gaeilge examples are not language-reviewed. No copyrighted paper/literary excerpts included. Rights/licence for future publication remains Dave’s decision.

The file is an editorial interchange format, not the proposed database schema or a safe student API response. Importer must reject duplicate IDs, invalid keys/links and ineligible combinations; production publication requires reviewed status and explicit reviewer evidence. Never serve this complete JSON to a learner before submission because it contains answer keys. The validator uses only Python standard library and validates structure, not factual accuracy, Irish quality or true educational equivalence across levels. year_guidance [1,2,3] indicates broad illustrative availability pending review, not a verified first-year outcome assignment.
